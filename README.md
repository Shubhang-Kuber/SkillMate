# SkillMate

**SkillMate** is a web-based platform designed to help engineering students navigate their learning journey, build professional resumes, and practice hackathons through a structured and interactive interface. It brings together learning resources, project simulation, and AI-powered evaluation into a single, student-friendly tool.

---

## Why SkillMate:

The project was developed to solve common challenges faced by engineering students, especially in their early semesters:

- Lack of clarity on how and where to start learning technical topics
- Misalignment between self-learning and college syllabus
- Confusion and inefficiency in building resumes
- Difficulty in interpreting hackathon problem statements and managing time effectively

SkillMate addresses these problems by providing a guided roadmap, template-based resume builder, and a realistic hackathon simulator with AI feedback.

---

## 🚀 Features

- **Skill Roadmap**  
  A visual and structured path to explore and learn technical and soft skills relevant to engineering students.

- **Resume Builder**  
  Allows students to build resumes in multiple templates: Traditional, Modern, and Technical, with easy formatting and export.

- **HackSim – Hackathon Simulator**  
  A dedicated module to simulate hackathons with:
  - Random problem statement generation
  - Code file and pitch submission
  - Real-time AI feedback using Google Gemini API
  - Scoring based on accuracy, innovation, clarity, and completeness

- **Flowchart-Based Instruction Template**  
  Guides students through proper submission structure and readiness checks before entering HackSim.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, HTML5, CSS3, JavaScript  
- **AI Integration:** Google Gemini API  
- **Design:** Responsive layout, accessibility support, modern UI
